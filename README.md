SauceDemo es una aplicación web diseñada para probar funcionalidades relacionadas con autenticación, navegación y flujos de compra en un comercio electrónico. Su propósito es simular casos de prueba comunes en entornos de desarrollo.

- Características principales de SauceDemo:

✔ Usuarios de prueba: Ofrece credenciales predefinidas para probar diferentes comportamientos y restricciones de acceso. Cuenta con un sistema de autenticación con diferentes tipos de usuarios.

✔ Simulación de comercio electrónico: Permite navegar por un catálogo, agregar productos al carrito, filtrar artículos y completar un proceso de pago. Simula un flujo de compra desde la selección de productos hasta el checkout. Incluye la creación de un conprobante de pago que se descarga automaticamente en formato PDF. 

✔ Entorno controlado: Contiene errores intencionales en algunos usuarios o elementos para practicar la detección de fallos.
